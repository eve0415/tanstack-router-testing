# @tanstack-router-testing/router-testing-core

Internal runtime primitives for TanStack Router/Start test harnesses.

This package provides framework-agnostic utilities: memory history, environment simulation, server function/middleware registries, and isolated middleware execution. It is a transitive dependency — most users should import from `@tanstack-router-testing/react-router-testing` or `@tanstack-router-testing/react-start-testing` instead.

## Install

```bash
pnpm add -D @tanstack-router-testing/router-testing-core
```
