# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Testing utilities for TanStack Router and TanStack Start. Monorepo with 4 packages under `packages/`:

- **react-router-testing** — `createRouterHarness`, `createTestRouter`, SSR harness, file route utilities (`computeFullPath`, `neuterAncestorLoaders`, `walkToRoot`)
- **react-start-testing** — `mockServerFn`, `mockMiddleware`, `createStartTestRuntime`, `createRscTestRuntime`, `clearStartMocks`, `runInStartEnv`, Vite plugin (`src/vite.ts`)
- **router-testing-core** — internal registry/env runtime (transitive dependency)

## Tooling

- **Type checker:** `@typescript/native-preview` (tsgo) — NOT the `typescript` package. Run `tsgo --noEmit`, not `tsc`.
- **Linter:** oxlint with type-aware checking via oxlint-tsgolint plugin
- **Formatter:** oxfmt (single quotes, no arrow parens, 160 print width, sorted imports)
- **Build:** tsdown (not tsup or esbuild)
- **Package manager:** pnpm 11 with workspaces (version pinned in `packageManager`)
- **Node:** min `>=22.12.0` (`engines.node`, tracks TanStack Start's floor); dev/CI runtime pinned to `24.18.x` (`devEngines.runtime`)

## Commands

```bash
pnpm build                    # build all packages (tsdown)
pnpm test:unit:core           # fast: core + integration tests
pnpm test:unit:vendored       # slow: all 110 vendored smoke tests (runs codegen first)
pnpm test:unit:vendored:examples      # subset: example apps only
pnpm test:unit:vendored:e2e-router    # subset: e2e router tests only
pnpm test:unit:vendored:e2e-start     # subset: e2e start tests only
pnpm test:types               # type-level assertions (tsgo --noEmit)
pnpm run lint                 # oxlint --fix + oxfmt (auto-fix)
pnpm run lint:check           # oxlint + oxfmt --check (CI)
```

Per-package (from package dir):

```bash
pnpm run build                # tsdown
pnpm run test:unit            # vitest run
pnpm run test:types           # tsgo --noEmit
```

## Code Style

- ESM only, no CJS
- Strict TypeScript: `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`
- `const` by default, no `var`
- `===` exclusively
- Template literals over concatenation
- Destructuring preferred
- Every public export needs TSDoc: summary + `@param` + `@returns` + `@example`
- Unit tests: colocated `src/**/*.test.ts` (router-testing-core) or `tests/unit/` (react-router-testing)
- Integration tests: `tests/integration/**/*.test.tsx`
- Vendored smoke tests: `tests/vendored/**/*.test.ts` (auto-generated by `scripts/gen-vendor-smoke-tests.mjs`)

## Architecture Notes

- Real router instances, not stubs — tests exercise actual `createRouter`, route trees, memory history
- The Start shim (`react-start-testing/src/shim.ts`) replaces `@tanstack/react-start` at test time via Vite alias
- `vendor/` contains 110 vendored TanStack example apps for smoke testing (excluded from workspace)

## Gotchas

- Vendored smoke tests in `tests/vendored/` are **codegen'd** — don't edit them directly; modify `scripts/gen-vendor-smoke-tests.mjs` instead
- The Start shim (`react-start-testing/src/shim.ts`) aliases `@tanstack/react-start` at test time — test files must never import directly from `@tanstack/react-start`
- `pnpm test:unit:vendored` auto-runs `test:vendored:prepare` (codegen + parity check); the subset commands (`vendored:examples`, etc.) also chain it
